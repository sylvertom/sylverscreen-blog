# Sylverscreen Blog

Personal tech blog covering Rails development, IoT projects, and electronics experiments.

## Setup

```bash
bundle install
bundle exec jekyll serve
```

Visit `http://localhost:4000` to preview the blog locally.

## Update

```bash
bundle update
```

## Writing Posts

Create new posts in `_posts/` with the format: `YYYY-MM-DD-title.md`

## Deployment

This blog is deployed to [sylverscreen.com](https://sylverscreen.com)

## Services & Tools

- **Static Site Generator**: [Jekyll](https://jekyllrb.com/)
- **Theme**: [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy)
- **Comments**: [Giscus](https://giscus.app/) (GitHub Discussions)
- **Hosting**: GitHub Pages
